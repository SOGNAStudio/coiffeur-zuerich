# 💇‍♀️ Coiffeur Zürich – Website

Moderne, responsive Website für einen Coiffeur-Salon in Zürich.  
Erstellt mit HTML, CSS und JavaScript.

---

## ✨ Projektbeschreibung

Diese Website wurde entwickelt, um einen modernen und stilvollen Online-Auftritt für einen Coiffeur-Salon zu schaffen.  
Der Fokus liegt auf klarer Struktur, visueller Qualität und einer angenehmen User Experience.

---

## 🧭 Seitenstruktur

- 🏠 **Home** – Startseite mit Hero-Bereich und Überblick  
- ✂️ **Leistungen** – Übersicht der Services inkl. Preis & Beschreibung  
- 🖼️ **Galerie** – Inspiration und Styling-Beispiele  
- 🔄 **Vorher / Nachher** – Transformationen von Haarschnitten & Stylings  
- 📅 **Termin** – Buchungsbereich für Termine  
- 📞 **Kontakt** – Kontaktformular & Standortinfos  

---

## ⚡ Features

- Fully responsive Design (Mobile & Desktop)
- Modernes, minimalistisches UI
- Starke visuelle erste Impression (Hero Section)
- Strukturierte Service-Darstellung
- **Before/After Slider für Hairstyling-Ergebnisse**
- Galerie mit visuellen Referenzen
- Call-to-Action für Terminbuchung
- Kontaktformular
- Klare Navigation & UX Flow

---

## 🖥️ Technologien

- HTML5  
- CSS3  
- JavaScript (Vanilla)

---

## 🎯 Ziel des Projekts

Ziel war es, eine moderne, ästhetische und benutzerfreundliche Website für einen Coiffeur-Salon zu erstellen, die:

- auf den ersten Blick Kund:innen anspricht  
- Vertrauen durch Design und Struktur aufbaut  
- und aktiv zu Terminbuchungen führt
